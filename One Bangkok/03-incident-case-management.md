## ขอบเขตการใช้

ใช้เป็นบริบทสำหรับ Claude และใช้ตรวจหัวข้อที่ต้องอ้างอิงต่อ ขั้นตอนและเกณฑ์ปฏิบัติงานจริงอ้างอิงเอกสารหรือไฟล์ฉบับที่นุ่นยืนยันล่าสุดตามขอบเขตงาน

## WK-OBK-CASE-001 รับแจ้งและเปิดเคส

บันทึกเวลาและช่องทางที่ SOC รับแจ้ง ตรวจสถานที่ และเทียบกับเคสที่มีอยู่เพื่อลดการเปิดซ้ำ ใช้ Case ID เป็นตัวอ้างอิงตลอดการประสานและติดตาม บันทึกเหตุจากการรับข้อมูล การตรวจ Virtual Patrol หรือการเฝ้าระวังด้วยแท็กที่ตรงกับแหล่งที่มา

## WK-OBK-CASE-002 จำแนกเหตุและตรวจหลักฐาน

เลือก Event Category, Event Type, Sub Event Type และ CAT ตาม Mozart Master และลักษณะเหตุจริง แยกสิ่งที่ผู้แจ้งรายงานจากสิ่งที่ SOC ตรวจยืนยัน ใช้ภาพและผลตรวจหน้างานประกอบการระบุ Actual หรือ False หัวข้อที่ยังตีความไม่ได้ให้ส่งตรวจตามเกณฑ์ของไซต์

## WK-OBK-CASE-003 ประสานงานและยกระดับ

ระบุหน่วยงานเจ้าของเหตุและผู้รับประสาน บันทึกเวลาที่ส่งต่อ ผู้รับเรื่อง สิ่งที่ขอให้ตรวจ และเวลาที่ได้รับผล หากเหตุมีผลกระทบต่อคนหรือการดำเนินงาน ให้ใช้ SOP และ Authority Matrix ฉบับที่มีผลของไซต์

## WK-OBK-CASE-004 Resolve และ Close

Findings ควรสรุปผลตรวจและหลักฐาน ส่วน Resolution บันทึกการดำเนินการและผลลัพธ์ ตรวจเจ้าของงานค้าง หลักฐาน และสถานะก่อน Close สำหรับการประเมิน ให้คงเวลาที่เกิดขึ้นจริงของแต่ละสถานะและแยกชื่อผู้ดำเนินการในแต่ละขั้น
