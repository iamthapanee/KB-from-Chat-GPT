## วัตถุประสงค์และขอบเขต

บันทึกเวลาและช่องทางที่ SOC รับแจ้ง ตรวจสถานที่ และเทียบกับเคสที่มีอยู่เพื่อลดการเปิดซ้ำ ใช้ Case ID เป็นตัวอ้างอิงตลอดการประสานและติดตาม บันทึกเหตุจากการรับข้อมูล การตรวจ Virtual Patrol หรือการเฝ้าระวังด้วยแท็กที่ตรงกับแหล่งที่มา

## ข้อมูลนำเข้าและหลักฐาน

เวลาแจ้งจริง, ช่องทาง, สถานที่ และผลตรวจเบื้องต้น

## ขั้นตอนการปฏิบัติงาน

1. ค้นเคสเดิมด้วยเวลาและพื้นที่
2. เลือกแหล่งที่มาของเหตุ
3. ใส่แท็กและเวลาใน Summary
4. ตรวจข้อมูลและบันทึก Case ID

## จุดตรวจสอบและข้อจำกัด

ถ้าเวลาแจ้งไม่ชัด ให้ระบุรอตรวจและรักษาข้อความต้นทาง
