## วัตถุประสงค์และขอบเขต

บันทึกขอบเขตของ Creation SLA, Security Resolve, Security Close, Security Trend, Pass/Fail Summary, Location Map, Sensetime VA และ Case Status Tracker งานต่อยอดที่เคยขอรวม Event Type Analysis และ Case Ranking พร้อมช่วงวัน สัปดาห์ และเดือน ตรวจชีทจริงก่อนระบุสถานะใช้งานของแต่ละ Module

## ข้อมูลนำเข้าและหลักฐาน

รายการ Module, สูตร Pilot และช่วงนำเข้าที่ตรวจได้

## ขั้นตอนการปฏิบัติงาน

1. ตรวจขอบเขตแต่ละ Module
2. เทียบตัวอย่างเคสผ่าน ไม่ผ่าน และรอตรวจ
3. ตรวจแถวท้ายชุดข้อมูล
4. บันทึกสถานะ Module

## จุดตรวจสอบและข้อจำกัด

หัวข้อขยาย Event Type Analysis และ Case Ranking ให้ตรวจชีทจริงก่อนรายงานว่าเปิดใช้งาน
