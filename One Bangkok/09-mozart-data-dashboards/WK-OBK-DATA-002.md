## วัตถุประสงค์และขอบเขต

นำเข้าแบบ upsert ตาม Case ID เพื่อให้เคสเดิมสะท้อนสถานะล่าสุดและรักษาข้อมูลเดือนที่อยู่นอกช่วงนำเข้า เมื่อข้อมูลซ้อนเดือน ตรวจค่าที่เปลี่ยน รายการซ้ำ และผลรวมหลังอัปเดต บันทึกช่วง Export และเวลานำเข้าเพื่อให้กลับไปเทียบไฟล์ได้

## ข้อมูลนำเข้าและหลักฐาน

ชุดนำเข้าใหม่และข้อมูลสะสมตาม Case ID

## ขั้นตอนการปฏิบัติงาน

1. ตรวจคีย์ซ้ำในชุด
2. เปรียบเทียบการเปลี่ยนแปลง
3. upsert เฉพาะ Case ID ที่พบ
4. ตรวจข้อมูลนอกช่วงนำเข้า

## จุดตรวจสอบและข้อจำกัด

ตัวอย่างนำเข้า Aug–Oct แล้ว Sep–Nov ต้องยังพบข้อมูล Aug และเคส Sep–Oct ใช้ผลล่าสุดตามกติกา
